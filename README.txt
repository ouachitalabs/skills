This is a repo containing the skills I have personally authored for my own gain.
Free to distribute and modify according to the apache LICENSE.

Use at your own risk. :-)

Skills are a way to package knowledge for coding agents.
Read more here https://code.claude.com/docs/en/skills.

`extensions/` holds pi extensions rather than skills — code that adds tools to the
[coding agent](https://github.com/earendil-works/pi), e.g. `extensions/openapi-bridge/`
turns any OpenAPI spec into two codemode-friendly tools.
